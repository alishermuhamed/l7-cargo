# Agent Guidelines

This file defines instructions for coding agents working in `apps/web`.

## Project Overview

- `apps/web` is the frontend application for this monorepo.
- Built with Vite and React.
- Uses TanStack Router for routing and TanStack Query for server state.
- Uses Radix UI Themes as the primary component and styling system.
- Uses Orval to generate API client code.
- Consumes shared code from `@l7-cargo/shared`.

## Authentication

This app uses [Better Auth](https://better-auth.com/llms.txt), auth client is defined in `src/lib/auth-client.ts`. Do not guess Better Auth types, method names, return shapes, or plugin APIs. Verify them in the docs first, then implement against the documented client API.

## Routing

This app uses [TanStack Router](https://tanstack.com/router/latest/docs/framework/react/overview) for routing. Always consult the official docs before changing route structure, navigation, loaders, search params, or route typing, and do not guess TanStack Router APIs or types.

## UI Component Library

### Radix UI Themes

This project uses [Radix UI Themes](https://www.radix-ui.com/themes) as the primary UI component library. **Always prefer Radix components over custom implementations or other libraries.**

### Styling

- Use Radix's built-in props for styling (e.g., `gap`, `p`, `m`, `size`).
- For custom styling, use the `className` prop with CSS modules.
- Design and implement UI mobile first, then enhance for larger breakpoints.
- Avoid inline styles unless absolutely necessary.

### Best Practices

1. **Always check Radix UI Themes documentation first** before creating custom components
2. Leverage Radix's responsive props (e.g., `<Flex direction={{ initial: 'column', md: 'row' }}>`)
3. Use Radix's theming system for colors, spacing, and typography
4. Keep layouts simple and composable using `<Flex>` and `<Box>`
5. Whenever the API contract changes, run `npm run generate:api` to regenerate the Orval client and keep `src/lib/api/api.gen.ts` in sync.

## Do Not Modify

- **`src/routeTree.gen.ts`** - This file is automatically generated by TanStack Router. Never edit this file manually. It will be regenerated automatically when route files are created or modified.
- **`src/lib/api/api.gen.ts`** - This file is automatically generated by Orval. Never edit this file manually. Update the OpenAPI source or `orval.config.js`, then regenerate it with `npm run generate:api`.
